# Java Foundation: Learning Journey 🚀

This repository serves as my personal knowledge base for Java core concepts. It is structured to demonstrate my progress from basic syntax to more complex logic.

## 📂 Project Structure

Everything is organized by topic to maintain clean code standards:

- **Basics**: Core syntax including `if-else` statements, `ternary` operators, and fundamental loops.
- **Methods**: Implementation of logic through methods, including calculation tools.
- **Arrays_and_cycles**: Deep dive into array manipulation and algorithmic tasks.
- **Practice**: Real-world exercises, user input handling, and mini-projects like `TicTacToeApp`.

## 🛠 Skills & Tools
- **Language**: Java 
- **IDE**: IntelliJ IDEA
- **Version Control**: Git (managing `.gitignore`, clean commit history, and branch merging).
- **Principles**: Clean naming conventions and logical project structuring.
